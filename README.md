# Laravel para PHP IDE

Rotas, views, Blade, configurações, traduções e Eloquent para Laravel.

## Instalar

No PHP IDE 0.2.9 ou superior, abra **Aparência → Plugins… → Instalar pelo Git** e informe:

`https://github.com/phpforge-dev/plugin-laravel`

Você também pode procurar **Laravel** no Marketplace. O plugin solicita leitura do projeto para encontrar arquivos e símbolos; não executa scripts nem acessa a rede. A sintaxe e os serviços nativos continuam na IDE.

## Desenvolvimento

`npm ci` instala as ferramentas e `npm run build` gera `main.js`. O pacote instalável está na raiz: não é necessário compilar ao instalar pela IDE. O código começou no PHP IDE e mantém a licença MIT e os créditos de Jeidison Farias.
